# 🔧 Поправка на DNS след 12 часа чакане

## Проблем:
DNS все още не се е разпространил след 12 часа. Проверката показва че `www.marbaras.com` сочи към `marbaras.com` вместо към Railway.

## Решение:

### Стъпка 1: Провери какво Railway очаква СЕГА

1. Отиди на **Railway Dashboard** → **Settings** → **Domains**
2. Намери `www.marbaras.com` в списъка
3. Кликни на него (или на "View DNS")
4. **Копирай точно CNAME стойността** която Railway показва (напр. `sn6khg43.up.railway.app` или `1v861vtj.up.railway.app`)

### Стъпка 2: Провери DNS в jump.bg

1. Отиди на jump.bg DNS мениджъра
2. Намери CNAME запис за `www`
3. **Убеди се че стойността СЪВПАДА точно** с това което Railway показва
4. Ако НЕ съвпада:
   - Кликни на редактиране (или изтрий и добави отново)
   - Хост: `www`
   - Тип: `CNAME`
   - Стойност: **[ТОЧНО това което Railway показва]**
   - TTL: `14400` или `3600`
   - **ВАЖНО: Кликни "Запази промените" (Save changes)**

### Стъпка 3: Изтрий и добави отново в Railway (ако е необходимо)

Ако Railway все още показва "Incorrect DNS setup":

1. В Railway → Settings → Domains
2. Намери `www.marbaras.com`
3. Кликни **Delete** (изтрий го)
4. Изчакай 1-2 минути
5. Кликни **"+ Custom Domain"**
6. Въведи: `www.marbaras.com`
7. Railway ще покаже **НОВА** CNAME стойност
8. Копирай тази стойност

### Стъпка 4: Обнови DNS в jump.bg с новата стойност

1. Отиди на jump.bg DNS мениджъра
2. Намери CNAME за `www`
3. Редактирай стойността да съвпада с новата от Railway
4. **Запази промените**

### Стъпка 5: Проверка на DNS разпространение

Използвай онлайн DNS checker:

1. Отиди на: https://dnschecker.org/
2. Въведи: `www.marbaras.com`
3. Избери тип: `CNAME`
4. Кликни "Search"
5. Провери дали **всички сървъри** показват правилната Railway стойност

**Ако някои сървъри все още показват старата стойност:**
- Изчакай още 30-60 минути
- DNS може да отнеме до 48 часа за пълно разпространение

### Стъпка 6: Изчисти DNS кеш (локално)

На твоя компютър:

```bash
# macOS
sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder

# Windows (в Command Prompt като администратор)
ipconfig /flushdns

# Linux
sudo systemd-resolve --flush-caches
```

### Стъпка 7: Проверка след 30 минути

1. Провери отново в Railway → Settings → Domains
2. Трябва да видиш "Active" (зелена отметка) за `www.marbaras.com`
3. Тествай в браузър: `https://www.marbaras.com`

---

## Често срещани проблеми:

### 1. CNAME стойността не съвпада точно
- **Решение:** Убеди се че копираш точно стойността от Railway (включително `.up.railway.app`)

### 2. Не си запазил промените в jump.bg
- **Решение:** След редактиране на DNS запис, **задължително** кликни "Запази промените"

### 3. Railway очаква друга стойност
- **Решение:** Изтрий домейна в Railway и добави го отново, за да получиш актуална CNAME стойност

### 4. DNS кеш проблем
- **Решение:** Изчисти DNS кеша на компютъра и използвай DNS Checker за глобална проверка

---

## Проверка на промените:

След като направиш промените, изчакай 15-30 минути и провери:

```bash
# Проверка на CNAME
dig www.marbaras.com CNAME +short

# Трябва да видиш нещо като:
# 1v861vtj.up.railway.app.
# или
# sn6khg43.up.railway.app.
```

Ако все още виждаш `marbaras.com.`, значи DNS все още не е разпространен.

## Ако след 24 часа все още не работи:

1. Провери дали jump.bg DNS сървърите са правилно конфигурирани
2. Свържи се с поддръжката на jump.bg
3. Провери Railway logs за грешки
4. Сподели:
   - Какво показва Railway → Settings → Domains
   - Какво показва DNS Checker
   - Какво показва `dig www.marbaras.com CNAME +short`
