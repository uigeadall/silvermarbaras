# 🔧 Проверка на Railway DNS проблеми

## Проблем:
Railway все още показва "Incorrect DNS setup" за `www.marbaras.com`.

## Решение:

### Стъпка 1: Виж какво точно очаква Railway

1. В Railway → Settings → Networking
2. Намери `www.marbaras.com` в списъка
3. Кликни на **"Show setup issues"** (в жълтото предупреждение)
4. Railway ще покаже какво точно очаква за DNS

**Възможни проблеми:**
- Railway очаква CNAME за `@` (root domain) вместо за `www`
- Railway очаква различна CNAME стойност
- DNS все още не се е разпространил достатъчно

### Стъпка 2: Провери DNS разпространение

1. Отиди на: https://dnschecker.org/
2. Въведи: `www.marbaras.com`
3. Тип: `CNAME`
4. Провери дали повечето сървъри показват `rlvxys18.up.railway.app`

**Ако повечето сървъри все още показват `marbaras.com`:**
- DNS все още не се е разпространил
- Изчакай още 30-60 минути

### Стъпка 3: Провери Railway CNAME стойност

1. Кликни на `www.marbaras.com` в Railway
2. Railway ще покаже каква CNAME стойност очаква
3. Убеди се че съвпада с `rlvxys18.up.railway.app`

**Ако Railway показва РАЗЛИЧНА стойност:**
- Обнови CNAME в jump.bg с новата стойност
- Запази промените

### Стъпка 4: Поправи жълтото предупреждение в jump.bg

1. Отиди на jump.bg DNS мениджъра
2. Кликни **"Пресъздай DNS зоната!"** (жълт бутон)
3. Това ще пресъздаде DNS зоната и ще поправи несъвпаденията
4. Изчакай 5-10 минути

### Стъпка 5: Провери отново в Railway

1. След 30-60 минути, отиди на Railway → Settings → Networking
2. Намери `www.marbaras.com`
3. Кликни **"Check DNS"** (ако има такъв бутон)
4. Railway трябва да покаже "Active" (зелена отметка)

---

## Важно:

- Railway може да показва "Incorrect DNS setup" дори когато DNS е правилно конфигуриран, но все още не се е разпространил
- Изчакай достатъчно време за DNS да се разпространи (30-60 минути)
- Поправи жълтото предупреждение в jump.bg като кликнеш "Пресъздай DNS зоната!"

---

## Проверка:

След 30-60 минути, провери:

1. DNS Checker - трябва да показва `rlvxys18.up.railway.app` за повечето сървъри
2. Railway → Settings → Networking - трябва да показва "Active" вместо "Incorrect DNS setup"
3. Браузър - `https://www.marbaras.com` трябва да работи

---

## Ако след 2 часа все още не работи:

1. Кликни на "Show setup issues" в Railway за да видиш какво точно очаква
2. Провери дали CNAME стойността в jump.bg съвпада с това което Railway очаква
3. Провери дали nameservers-ите на домейна са правилни
4. Свържи се с поддръжката на jump.bg или Railway
