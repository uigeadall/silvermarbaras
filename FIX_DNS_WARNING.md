# 🔧 Поправка на DNS предупреждение и разпространение

## Проблем:
1. DNS все още не се е разпространил след 12 часа
2. Жълто предупреждение в jump.bg: "ДНС сървърите на домейна не съвпадат с НС записите в тази зона"
3. Проверката показва че `www.marbaras.com` сочи към `marbaras.com` вместо към Railway

## Решение:

### Стъпка 1: Провери DNS сървърите на домейна

1. Отиди на jump.bg → **Домейни** → **marbaras.com**
2. Провери кои са DNS сървърите (nameservers) за домейна
3. Те трябва да са:
   - `ns1.jumphosting01.com`
   - `ns2.jumphosting01.com` (или друг jump.bg nameserver)

**Ако DNS сървърите НЕ са jump.bg:**
- Това е проблемът! DNS записите в jump.bg няма да работят ако домейнът използва други nameservers
- Трябва да промениш nameservers-ите на домейна да сочат към jump.bg

### Стъпка 2: Поправи DNS зоната (ако е необходимо)

Ако предупреждението все още е там:

1. В DNS мениджъра, кликни на **"Пресъздай DNS зоната!"** (жълт бутон)
2. Това ще пресъздаде DNS зоната и ще поправи несъвпаденията
3. Изчакай 5-10 минути

### Стъпка 3: Провери Railway CNAME стойност

1. Отиди на **Railway Dashboard** → **Settings** → **Domains**
2. Намери `www.marbaras.com`
3. Провери каква CNAME стойност показва Railway
4. Убеди се че съвпада с `1v861vtj.up.railway.app`

**Ако Railway показва РАЗЛИЧНА стойност:**
- Изтрий `www.marbaras.com` в Railway
- Добави го отново
- Копирай новата CNAME стойност
- Обнови DNS запис в jump.bg

### Стъпка 4: Обнови DNS запис в jump.bg

1. В DNS мениджъра, намери CNAME за `www`
2. Убеди се че стойността е точно: `1v861vtj.up.railway.app` (или каквото Railway показва)
3. **ВАЖНО:** Убеди се че НЕ завършва с точка (`.`) в края
4. Кликни **"Запази промените"** (син бутон)

### Стъпка 5: Изчакай и провери

1. Изчакай 15-30 минути
2. Провери в Railway → Settings → Domains дали `www.marbaras.com` е "Active"
3. Използвай [DNS Checker](https://dnschecker.org/):
   - Въведи: `www.marbaras.com`
   - Тип: `CNAME`
   - Провери дали всички сървъри показват `1v861vtj.up.railway.app`

### Стъпка 6: Ако все още не работи - изтрий и добави отново в Railway

1. В Railway → Settings → Domains
2. Изтрий `www.marbaras.com`
3. Изчакай 2-3 минути
4. Добави отново `www.marbaras.com`
5. Railway ще покаже **НОВА** CNAME стойност
6. Обнови DNS в jump.bg с новата стойност
7. Запази промените

---

## Често срещани проблеми:

### 1. DNS сървърите не са jump.bg
**Решение:** Промени nameservers-ите на домейна да сочат към jump.bg

### 2. CNAME стойността завършва с точка
**Решение:** Убеди се че CNAME стойността е `1v861vtj.up.railway.app` (БЕЗ точка в края)

### 3. Не си запазил промените
**Решение:** След всяка промяна, кликни "Запази промените"

### 4. DNS кеш проблем
**Решение:** Изчакай още 30-60 минути. DNS може да отнеме до 48 часа за пълно разпространение.

---

## Проверка:

След промените, използвай тези команди за проверка:

```bash
# Проверка на CNAME (трябва да видиш Railway стойност)
dig www.marbaras.com CNAME +short

# Проверка с Google DNS
dig @8.8.8.8 www.marbaras.com CNAME +short

# Проверка с Cloudflare DNS
dig @1.1.1.1 www.marbaras.com CNAME +short
```

**Очакван резултат:** `1v861vtj.up.railway.app.` (или каквото Railway показва)

---

## Ако след 24 часа все още не работи:

1. Провери дали nameservers-ите на домейна са правилно конфигурирани
2. Свържи се с поддръжката на jump.bg
3. Провери Railway logs за грешки
4. Сподели:
   - Какви са DNS сървърите (nameservers) на домейна
   - Какво показва Railway → Settings → Domains
   - Какво показва DNS Checker
