# 🔧 Поправка на Media Файловете в Railway

## Проблем
Снимките на продуктите и банерът не се показват, защото:
1. В Railway файловата система е **ефемерна** - файловете се изтриват при всеки redeploy
2. Media файловете трябва да се съхраняват в **Railway Volume** (персистентно хранилище)

## Решение: Railway Volume

### Стъпка 1: Създай Volume в Railway Dashboard

1. Отиди на Railway Dashboard: https://railway.app/dashboard
2. Избери проекта си
3. Избери service-а (обикновено `marbaras` или името на приложението)
4. Отиди на таба **"Settings"**
5. Скролни до секцията **"Volumes"**
6. Кликни **"+ New Volume"**
7. Попълни:
   - **Name**: `media-volume`
   - **Mount Path**: `/app/media`
8. Кликни **"Create"**

### Стъпка 2: Качи Съществуващите Media Файлове

След като създадеш Volume, трябва да качиш съществуващите media файлове:

#### Опция A: Използвай Railway CLI

```bash
# Инсталирай Railway CLI (ако нямаш)
npm i -g @railway/cli

# Свържи се към проекта
railway link

# Качи media файловете
railway run --service <service-name> rsync -avz ./media/ /app/media/
```

#### Опция B: Използвай Railway Dashboard Shell

1. В Railway Dashboard → твоя service
2. Отиди на таба **"Deployments"**
3. Кликни на последния deployment
4. Търси опция **"Shell"** или **"Console"**
5. Изпълни:

```bash
# Създай директориите
mkdir -p /app/media/products
mkdir -p /app/media/products/multiple

# Качи файловете (ще трябва да ги качиш чрез друг метод)
# Можеш да използваш wget или curl за да ги качиш от друг сървър
```

#### Опция C: Качи чрез Admin Panel

1. След като Volume е създаден, отиди на admin panel
2. Качи снимките отново чрез Django Admin
3. Те ще се запазят в Volume

### Стъпка 3: Проверка

1. Отиди на приложението
2. Провери дали снимките се показват
3. Отвори Developer Tools (F12) → Network tab
4. Провери дали снимките се зареждат от `/media/products/`

## Алтернатива: Cloud Storage (Препоръчително за Production)

За по-добра производителност и надеждност, препоръчвам да използваш cloud storage:

### Опции:

1. **Cloudinary** (безплатно до 25GB)
   - Лесно за интеграция
   - Автоматично оптимизация на снимки
   - CDN включен

2. **AWS S3** (pay-as-you-go)
   - Надеждно и мащабируемо
   - Изисква AWS акаунт

3. **Railway Volume** (текущо решение)
   - Просто, но по-скъпо
   - Файловете се запазват между деплоите

## Важни Бележки

- **Volume трябва да бъде създаден ПРЕДИ да качваш файлове**
- **Файловете в Volume се запазват между деплоите**
- **Новите файлове, качени след създаването на Volume, ще се запазят**
- **Старите файлове трябва да се качат ръчно в Volume**

## Следващи Стъпки

1. ✅ Създай Railway Volume
2. ✅ Качи съществуващите media файлове
3. ✅ Тествай дали снимките се показват
4. ✅ Качи нови продукти и провери дали снимките се запазват

## Ако Проблемът Продължава

1. Провери Railway logs за грешки
2. Провери дали Volume е правилно монтиран (`/app/media`)
3. Провери правата за достъп до media директорията
4. Провери дали `MEDIA_ROOT` в settings.py е правилно настроен
